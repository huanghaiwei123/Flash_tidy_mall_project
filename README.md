# springboot-seckill-project
一个新手的个人练习项目，从0到1
技术选型：JDK 8 / SpringBoot 2.7.18 / MyBatis-Plus 3.5.5 / Redis (Lettuce) / MySQL / JWT (jjwt 0.12.5) / BCrypt / Knife4j 3.0.3
这是一个小白的自我进阶之路，是从一个新手的视角出发，并且在ai的加持下一点点完善的，因此注解都挺全的，这个项目有不足之处很正常，也欢迎大家给我提出你们宝贵的建议， 同时也希望你们能够通过我的项目回想起你们还是小白的时候刚开始写代码的那份最初的记忆
